    Contribute

    1. Check it's genuinely free: no paid tier, no trial. Closed-source tools that are free forever are fine, tagged free (proprietary).
    2. Add one row to the right file in data/categories/: website,name,tags,description.
    3. Open a pull request. The page reads the CSVs directly, so it updates once the PR is merged.
